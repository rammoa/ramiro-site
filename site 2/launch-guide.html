Launch Guide

Get ramiromorales.com live.

Your site is built. This is the click-by-click to put it online, take card payments, and route contact-form messages to your inbox. You only need a browser — no coding.

⏱ About 30–45 minutes
1

Put the files on GitHub easiest updates

Netlify pulls your site from GitHub and re-deploys automatically whenever you change something.
  1. Create a free account at github.com.
  2. Click New repository → name it ramiro-site → Create.
  3. On the repo page, click uploading an existing file, then drag in everything inside the site folder (not the folder itself — its contents). Commit.
Prefer no GitHub? You can skip straight to Step 2 and drag-and-drop the site folder onto Netlify. The trade-off: future updates mean re-dragging the folder instead of an automatic re-deploy.
2

Deploy on Netlify

Free hosting that runs your checkout function and contact form.
  1. Sign up at netlify.com (use "Sign up with GitHub").
  2. Click Add new site → Import an existing project → GitHub → pick ramiro-site.
  3. Leave the build settings as detected (the included netlify.toml sets them) → Deploy.
  4. In ~30 seconds you'll get a live link like random-name.netlify.app. Open it — your site is live.
3

Turn on card payments (Stripe)

Your prints already have a cart & checkout — this connects the money to you.
  1. Create a free account at stripe.com and finish the business details so you can accept live payments.
  2. Go to Developers → API keys and copy your Secret key.
    Testing?use the key starting sk_test_…Live?use the key starting sk_live_…
  3. In Netlify → Site configuration → Environment variables → Add a variable:
    KeySTRIPE_SECRET_KEYValuepaste your Stripe secret key
  4. Deploys → Trigger deploy → Deploy site so the key takes effect.
  5. Test it: add a print to the cart → Checkout → you should land on Stripe's payment page. Use Stripe's test card 4242 4242 4242 4242, any future date & CVC.
Your key stays private. It lives only in Netlify's server settings — never in the website code, and never shared with anyone (including me). The browser never sees it.
4

Send contact-form messages to your inbox

The About page form is wired to Netlify Forms — no code, just switch on the email.
  1. On your live site, open About, fill the form and submit once (this registers it with Netlify).
  2. In Netlify → Forms → contact → Settings & notifications → Add notification → Email notification.
  3. Enter ramiromorales234@gmail.com → save.
Every inquiry now emails you automatically, and is also saved under Netlify → Forms. Spam is filtered by a built-in honeypot.
5

Point your domain

Move ramiromorales.com from Squarespace to the new site.
  1. In Netlify → Domain management → Add a domain → enter ramiromorales.com.
  2. Netlify shows the DNS records to set. In your domain registrar (where you bought the domain), update them as shown. If the domain is currently managed inside Squarespace, you'll repoint it there or transfer it out first.
  3. Wait for it to verify (minutes to a few hours) — Netlify adds a free HTTPS certificate automatically.
Keep Squarespace live until this step is done and verified, so the site is never down. Cancel Squarespace only once the new site is up on your domain.
6

Make it yours

Quick edits, all in assets/js/data.js.
  • Prints, prices, sizes: the PRINT_ITEMS and PRINT_SIZES lists. Change a price in one place and re-deploy. (Then match ALLOWED_PRICES in netlify/functions/create-checkout.js.)
  • Own image hosting: images currently load from your Squarespace CDN. Later, export ~2000px JPGs from your Drive originals, host them (Netlify, Cloudinary), and swap the URLs.
  • Copy & bio: edit the text directly in the .html files.
